# Desktop execution

Fleet Runner is the optional desktop app for running project agents on your
computer. The current setup, execution routing, and troubleshooting guidance is
in [Cloud vs Local Workflows](development/cloud-local-workflows.md) and the
[Fleet Runner README](../desktop/README.md).

The original desktop migration plan is preserved as a dated historical record
in [the archive](archive/desktop-app-migration-plan.md). Its phases and
architecture descriptions are not current instructions.
